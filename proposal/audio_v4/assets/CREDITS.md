# Instrument sample attribution

Instrument bank: **FluidR3_GM / Fluid Soundfont**. Rendered samples distributed by the contributors to [gleitz/midi-js-soundfonts](https://github.com/gleitz/midi-js-soundfonts).

Source bank directory: <https://github.com/gleitz/midi-js-soundfonts/tree/gh-pages/FluidR3_GM>. The source repository identifies FluidR3_GM as licensed under [Creative Commons Attribution 3.0](https://creativecommons.org/licenses/by/3.0/us/). Its README is preserved in `SOURCE_README.md`.

Selected instruments: acoustic grand piano, electric piano 1, finger electric bass, nylon acoustic guitar and vibraphone. Only notes needed by the existing score were extracted. The samples are used with note envelopes, gain, panning, equalization and reverberation. `sample_manifest.json` records source URLs and hashes.

The original composition and application code have their own project license; the included instrument samples remain CC BY 3.0. Preserve this attribution with distributed audio/video, for example in the accompanying credits or publication description.
